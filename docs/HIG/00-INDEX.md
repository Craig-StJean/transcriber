# GNOME Human Interface Guidelines - Reference Documentation

This directory contains reference documentation based on the [GNOME Human Interface Guidelines (HIG)](https://developer.gnome.org/hig/). It serves as a practical guide for designing and building applications that integrate naturally with the GNOME desktop environment.

These documents cover design principles, UI patterns, controls, accessibility, and platform conventions. They are intended to be used alongside the official HIG, not as a replacement.
